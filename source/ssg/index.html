ssg/ Static Site Generator Architecture

Batch rendering, recursive asset synchronization, and preview serving.

Zero-Allocation Route Vectors

The MizarSite engine stores route render callbacks in a dynamic MzVec allocated from an internal MzArena. Pages render sequentially into reusable MizarBuffer instances and flush to disk via mz_fs_write_file.

Path Canonicalization & Traversal Defense

All static asset paths are validated using realpath() against the designated root directory, completely blocking directory traversal attacks (../) and unauthorized symlink resolution.
